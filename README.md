# 进阶 PMP · 你的备考工作台

个人 PMP 备考网站，针对有工作经验、PMP 零基础的在职学习者。英文为主，中文对照。

## 学习目标

跟着一门 35 小时的 Udemy 课程走（TIA Education，Andrew Ramdayal，2026 新考纲版），按在职节奏排成 12 周、每周 9 小时：前 8 周听课并练对应章节的题，第 8 周做课程自带模拟考试、领证书、提交 PMI 申请，后 4 周查漏、做难题和全长模拟。每周时长可在设置里改，周期随之伸缩。落后太多时可以“从今天重新排期”，已有记录保留。

## 内容与功能

- **今日**：计划应听到的课程时长对比实际已听，下面是今天要做的几件事：下一讲、一节提要、一组练习、到期复习。
- **听课**：课程 274 讲的目录（`docs/data/course.js`），听完一讲勾一讲；每个单元可以直接练对应主题的题，并链接到相关提要。
- **提要**：24 节原创知识提要。**练习**：200 道原创情景单选题，含解析和逐项排除理由；每日练习、诊断、章节练习、领域专项、60 题计时测试、180 题综合计时训练。
- 错题与收藏、间隔复习、题目和提要笔记、首次作答统计、专注计时、学习时长记录、JSON 备份导入导出。
- **语言分成两个设置**：学习内容（题目、提要）可选英文、英文加中文对照、中文，页面顶部随时切换；界面语言（菜单、按钮）单独选中文或英文。双语只作用于学习内容，英文在上、中文在下。
- 浅色和深色外观，可跟随系统；手机上用底部标签栏，答题时操作按钮固定在底部。

## 代码结构

- `docs/index.html`、`docs/app.css`、`docs/app.js`：页面、样式和界面逻辑。
- `docs/core.js`：计划日期、抽题、间隔复习、评分和备份校验，纯逻辑，有测试。
- `docs/i18n.js`：中文为源文本，英文由词典和规则生成；`data-zone="content"` 标记的区域按学习内容语言显示，其余按界面语言显示。
- `docs/data/`：课程目录、周计划与提要（`curriculum.js`）、题库和英文内容。

## 本地运行

静态源码与发布文件均在 `docs/`，不需要安装依赖或构建。

```sh
python3 -m http.server 4173 --directory docs
```

打开 http://localhost:4173 。核心逻辑和内容完整性测试：

```sh
node --test tests/*.test.cjs
```

## 数据与内容范围

学习记录仅保存在当前浏览器的 localStorage，不上传到仓库，也不自动跨设备同步。请定期导出备份。网站可公开访问；个人进度保留在浏览器。

这是独立原创学习辅助工具，不是 PMI 官方产品，不提供 35 小时培训证明，也不保证考试通过。所有练习模式共用 200 题；单选综合训练不复刻正式考试的全部题型、案例实操与休息流程。请结合合规培训、PMI 官方考试大纲及可靠来源的未见模拟题准备。75% 等数值是本站复习参考目标，不是 PMI 官方及格线。

官方信息核对日期：2026-11-13。网站工具箱提供 PMI、PMI China 与 Scrum Guide 官方来源。
